# Dinero mainnet fixed seed list.
#
# This file is the SOURCE OF TRUTH for the fixed seeds compiled into
# every dinerod / dinero-qt binary. Lines beginning with `#` are
# comments. Blank lines are ignored. Every non-comment line must be a
# single `IP:port` entry — one fixed seed per line, IPv4 only for now
# (IPv6 + addrv2 land later).
#
# When a new dinerod binary boots for the very first time and has no
# peers.dat, no DNS-resolved seeds (network down), and no explicit
# `-addnode` config, **this list is the only thing it can reach.** Pick
# entries with that in mind:
#
#   1. Stable: run dinerod 24/7 on hardware you operate or trust.
#   2. Reachable: must accept inbound connections on the listed port.
#   3. Geographically diverse: one DNS-seed outage shouldn't take out
#      the entire fixed list (different ISPs, different regions).
#   4. Independent operators: avoid concentrating all entries at one
#      operator. The whole point of fixed seeds is they survive the
#      DineroLabs-operated DNS seeds going down.
#
# To regenerate include/consensus/chainparamsseeds.h after editing this
# file:
#
#     python3 contrib/seeds/generate-seeds.py
#
# CMake also regenerates the header automatically on the next
# `cmake -B build` invocation when this file is newer than the header.
# CI uses `--check` mode to fail if the committed header drifted from
# this list.
#
