# Language picker flags

The SVG sources in this folder are from [flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3) under the MIT license in `LICENSE.flag-icons`. The PNG files are 64 × 48 renderings of those SVGs, embedded in the Qt app so flags display consistently on Windows, macOS, and Linux.

These flags identify the country most closely associated with each offered language. English uses the United Kingdom flag. Language names remain visible and are the authoritative choice; a flag alone does not define a language.
