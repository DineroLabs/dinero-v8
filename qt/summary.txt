WHAT WAS ADDED:

1. 📊 System Monitoring Section (Overview Tab Bottom Half)
   - CPU Usage: Progress bar showing mining thread utilization
   - Local Hashrate: Real-time hashrate from mining.info (H/s, KH/s, MH/s)
   - Network Hashrate: Network hashrate (H/s, KH/s, MH/s, GH/s)
   
2. 📦 Mempool Metrics
   - Transaction count (e.g., "512 txs")
   - Memory usage (bytes, KB, MB formatted)
   
3. 🌐 Network Metrics
   - Peer count with connectivity status
   - Status: Disconnected (red), Poor (yellow), Good (green)
   - Compact peers table (top 5 peers)
   - Columns: Address, Latency, Uptime, Version
   - Sortable table
   
4. ⚠️ Alerts Feed
   - Text area showing recent events
   - Logs peer disconnections
   - Logs export events
   - Last 5 alerts displayed
   
5. 📊 Export Metrics Button
   - JSON export: Complete metrics snapshot
   - CSV export: Tabular format with peers + alerts
   - Timestamped filenames (dinero-metrics-YYYYMMDD-HHMMSS)
   - User-friendly save dialog

DATA SOURCES:
  - mining.info → CPU, local hashrate, network hashrate
  - mempool.getinfo → Mempool size, bytes
  - p2p.getpeerinfo → Peers table, connectivity status
  - Auto-refreshes every 5 seconds

UI DESIGN:
