# W4 wallet-file fixture: Orchard backend ON

Generated by the baseline build; checked by ctest SepWalletFixtureCompat in every later stage
(docs/superpowers/specs/2026-10-29-wallet-node-separation-design.md section 8, W4).
Do not regenerate after the baseline: the point is that later builds open these exact files.

- Generator commit: e0d4a179d349ad94d3ab26b412e6a9682503ae59 (production sources src/ include/ rust/ resources/
  identical to baseline 1667f8ed6).
- Build: build-env.md configure, macOS arm64, Release, -DDINERO_BUILD_ORCHARD_BACKEND=ON
  -DDINERO_SEPARATION_GATES=ON -DDINERO_SEPARATION_FIXTURE_GEN=ON; target sep_make_wallet_fixture.
- Command (cwd = an empty scratch dir; relative outdir keeps machine paths out of the registry):
  `sep_make_wallet_fixture on`, then copied wallet_registry.db, wallets/wallet_sepfixture.db,
  blockchain/utxo, expected.json and schema.txt here.
- Generation is deterministic in every compared field (two independent runs gave byte-identical
  expected.json and schema.txt). The .db bytes differ per run (timestamps, random delivery id,
  AES-GCM nonces); the check compares derived content, not bytes.
