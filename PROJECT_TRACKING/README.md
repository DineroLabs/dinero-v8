# 📁 PROJECT_TRACKING Folder

**Purpose**: Single source of truth for DineroCoin development progress and planning

**⚠️ IMPORTANT FOR CLAUDE**: When starting a new chat or nearing context limit, read these files in this order:
1. **PROGRESS_SUMMARY.md** (read this FIRST - quick state snapshot)
2. **CURRENT_STATUS.md** (what's happening now)
3. **PRODUCTION_READINESS_ROADMAP.md** (full plan, if needed)
4. **PROGRESS_TRACKER.md** (detailed checklist)

---

## 📄 **File Guide**

### **PROGRESS_SUMMARY.md** 🌟
**Read This First!**
- **What**: Concise state of the project (1-2 pages max)
- **When**: Gets updated after every significant milestone
- **Contains**: Current phase, completed items, active work, blockers, next steps
- **Use Case**: Quick context recovery when starting new chat

### **CURRENT_STATUS.md**
**What's Happening Now**
- **What**: Detailed status of active work
- **When**: Updated daily or after each work session
- **Contains**: Today's tasks, test results, issues encountered, decisions made
- **Use Case**: Day-to-day work tracking

### **PRODUCTION_READINESS_ROADMAP.md**
**The Master Plan**
- **What**: Complete 6-week roadmap with all phases and milestones
- **When**: Reference document, updated when plan changes
- **Contains**: All phases, tasks, success criteria, timelines
- **Use Case**: Understanding overall strategy and dependencies

### **PROGRESS_TRACKER.md**
**The Detailed Checklist**
- **What**: Day-by-day checklist with test results
- **When**: Updated as tasks complete
- **Contains**: Every checkbox, test result, blocker log
- **Use Case**: Granular progress tracking

---

## 🔄 **Update Workflow**

### **After Each Work Session**:
1. Update CURRENT_STATUS.md with today's work
2. Check off items in PROGRESS_TRACKER.md
3. Log any blockers

### **After Each Milestone**:
1. Update PROGRESS_SUMMARY.md with new state
2. Update phase completion percentages
3. Document lessons learned

### **Before Context Limit**:
1. Update PROGRESS_SUMMARY.md with comprehensive state
2. Save any open issues to CURRENT_STATUS.md
3. Note next immediate tasks

---

## 🎯 **Quick Recovery Protocol**

**If starting fresh chat:**
```
1. Read: PROJECT_TRACKING/PROGRESS_SUMMARY.md
2. Ask: "What should I work on next?"
3. Proceed based on CURRENT_STATUS.md
```
