## Release Identification

### Git Tag

**Tag Name**: `v0.16.0-f6`

**Rationale**:
- `v0.16.0`: Minor version bump from v0.15.0-f5 (new certified subsystem)
- `-f6`: Phase identifier (Wallet State & Persistence Certification)
- Follows semantic versioning for scope-based releases

**Why not v0.15.1-f6**:
- F.6 certifies a new subsystem (wallet), not a patch to F.5 (mining)
- Minor version bump signals new certification scope

**Title**: `v0.16.0-f6 — Wallet State & Persistence Certified`

**Rationale**:

- Avoids vague language ("improvements", "refactor", "complete")
- Matches RELEASE_POLICY.md pattern from F.5

## Naming Principles

### ✅ DO Use

**Certification language**:
- "Wallet State & Persistence Certified"
- "Wallet persistence subsystem locked"
- "Invariants W.1–W.7 enforced"

**Objective claims**:
- "10/10 P0 tests passing"
- "Restart safety guaranteed"
- "Reorg handling validated"

**Scope clarity**:
- "Correctness certification, not feature completeness"
- "Production-grade for in-scope items"

### ❌ DO NOT Use

**Vague language**:
- ❌ "Wallet improvements"
- ❌ "Wallet refactor"
- ❌ "Phase F.6 complete"
- ❌ "Wallet enhancements"
- ❌ "Better wallet performance"

**Feature-focused language**:
- ❌ "New wallet features"
- ❌ "HD wallet support"
- ❌ "Multi-signature ready"

**Absolute claims**:
- ❌ "Wallet is perfect"
- ❌ "All wallet bugs fixed"
- ❌ "Mainnet ready"

**Reason**: Release certifies correctness for defined scope (W.1–W.7), not feature completeness or perfection.

## Version Numbering Scheme

### Pattern

`v<major>.<minor>.<patch>-<phase>`

**For F-series phases**:
- F.5 (mining): `v0.15.0-f5`
- F.6 (wallet): `v0.16.0-f6`
- F.7 (future): `v0.17.0-f7`

**Rationale**:
- Each certified subsystem gets a minor version bump
- Patches (v0.16.1) for bug fixes within certified scope
- Major version (v1.0.0) reserved for mainnet launch

### When to Bump

- **Minor version** (+1): New subsystem certified (F.5 → F.6)
- **Patch version** (+1): Bug fix within certified scope
- **Major version** (+1): Mainnet launch or breaking protocol change
