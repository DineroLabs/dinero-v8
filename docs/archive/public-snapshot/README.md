# Public Snapshot Archive

This directory holds historical material that was useful during the original
public v8 source snapshot, but does not need to sit at the repository root.

The move is organizational only. The files are kept for provenance and audit
history.

## Contents

- `audit/` - historical audit package and threat-model notes
- `tracking/` - older project tracking and status documents
- `fixtures/` - old genesis/test fixture outputs and RPC response captures
- `root-artifacts/` - one-off text/json result files from earlier development

Current source, builds, packaging, and tests remain in their normal top-level
directories.
