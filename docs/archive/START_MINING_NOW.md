## Quick Start (2 minutes):

### 1. Open the GUI Window
Look for the **"Dinero Cryptocurrency Wallet"** window on your screen.

### 2. Generate a Mining Address
- Click the **"Wallet"** tab
- Click **"Generate New Address"** button
- You'll see an address like: `din1qac9pfuncurxxf3w2zkv46ft6x76rakl4akx0e6`
- **Copy this address** (click the Copy button)

### 3. Start Mining!
- Click the **"⛏️ Mining"** tab
- Click **"Use Wallet Address"** button (it will auto-fill your address)
- Make sure **Threads** is set to `8` (or adjust to your preference)
- Click the big green **"▶️ Start Mining"** button

### 4. Watch the Magic! ✨

You should immediately see:
- Status bar turns green: **"⛏️ Mining to din1qac9..."**
- The **Mining Output** window fills with text:
  ```

  ⛏️  1.23 MH/s | Total: 45 MH | Blocks: 0
  ```
