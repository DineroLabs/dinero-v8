# Downloads and Releases

Most users should use the current stable `v8.1.3` release from the Releases page:

https://github.com/DineroLabs/dinero-v8/releases

The source tree is mainly for developers and operators. If you are not intentionally building from source, use the release assets.

## Choosing an Asset

- Desktop wallet: choose the signed asset for your operating system.
- Server/operator node: use the Linux package or tarball described in the release notes.
- Developers: clone the repository and build from source.

## Verification

When checksums or signatures are provided, verify the release asset before running it.

The repository contains older release candidates for provenance. Use `v8.1.3`
unless a maintainer has asked you to test a specific older build.
