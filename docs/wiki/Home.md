# Dinero v8 Wiki

If you only want to download or run Dinero, start here rather than reading the full source tree. The repository itself is a monorepo for daemon, desktop wallet, NodeCore/mobile runtime, mining, packaging, and tests.

## What Belongs Where

Use Discussions for questions, setup help, and design conversations that are not confirmed bugs yet.

Use Issues for confirmed bugs with logs, exact versions, and reproduction steps.

Use Pull Requests for proposed source, documentation, packaging, or test changes.
