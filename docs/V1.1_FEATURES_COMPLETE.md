#### Core Metrics Tracked

##### 1. Uptime Tracking ✅
**Implementation**:
```cpp
struct ReputationMetrics {
    // Cumulative uptime (lifetime)
    std::chrono::seconds cumulative_uptime;

    // Current session uptime
    std::chrono::system_clock::time_point session_start;

    // First seen timestamp
    std::chrono::system_clock::time_point first_seen;

    // Calculate uptime percentage
    double getUptimePercentage() const {
        auto total_time = std::chrono::system_clock::now() - first_seen;
        return (cumulative_uptime.count() / total_time.count()) * 100.0;
    }
};
```

**Tracking Logic**:
- Session start recorded on connection
- Session end recorded on disconnection
- Cumulative uptime updated on each disconnect
- Uptime percentage: `cumulative_uptime / (now - first_seen)`

##### 2. Latency Measurement ✅
**Implementation**:
```cpp
struct LatencyMetrics {
    double average_latency_ms;  // Exponential moving average
    double min_latency_ms;
    double max_latency_ms;
    uint32_t ping_count;

    // Update with new ping measurement
    void recordPing(double latency_ms) {
        // Exponential moving average (alpha = 0.1)
        average_latency_ms = 0.9 * average_latency_ms + 0.1 * latency_ms;

        min_latency_ms = std::min(min_latency_ms, latency_ms);
        max_latency_ms = std::max(max_latency_ms, latency_ms);
        ping_count++;
    }
};
```

**Algorithm**: Exponential Moving Average (EMA)
- Reacts quickly to changes
- Smooths out outliers
- Memory-efficient (no history storage)

##### 3. Reliability Ratio ✅
**Implementation**:
```cpp
struct ReliabilityMetrics {
    uint32_t connection_attempts;
    uint32_t successful_connections;
    uint32_t failed_connections;

    // Calculate reliability ratio
    double getReliabilityRatio() const {
        if (connection_attempts == 0) return 0.0;
        return (double)successful_connections / connection_attempts;
    }
};
```

**Tracking Logic**:
- Connection attempt recorded on dial
- Successful connection recorded on handshake complete
- Failed connection recorded on timeout/error
- Reliability ratio: `successful / attempts`

#### Reputation Score Calculation

**Composite Score** (0-100):
```cpp
int32_t calculateReputationScore(const ReputationMetrics& metrics) {
    int32_t score = 50;  // Start at neutral

    // Uptime bonus (max +20)
    if (metrics.uptime_percentage > 99.0) score += 20;
    else if (metrics.uptime_percentage > 95.0) score += 15;
    else if (metrics.uptime_percentage > 90.0) score += 10;

    // Latency bonus (max +15)
    if (metrics.average_latency_ms < 50.0) score += 15;
    else if (metrics.average_latency_ms < 100.0) score += 10;
    else if (metrics.average_latency_ms < 200.0) score += 5;

    // Reliability bonus (max +15)
    if (metrics.reliability_ratio > 0.95) score += 15;
    else if (metrics.reliability_ratio > 0.90) score += 10;
    else if (metrics.reliability_ratio > 0.80) score += 5;

    // Misbehavior penalty
    score -= metrics.misbehavior_score;

    return std::clamp(score, 0, 100);
}
```

**Score Interpretation**:
- **80-100**: Excellent peer (fast, reliable, no misbehavior)
- **60-79**: Good peer (generally reliable)
- **40-59**: Average peer (acceptable)
- **20-39**: Poor peer (slow or unreliable)
- **0-19**: Bad peer (frequent misbehavior)
