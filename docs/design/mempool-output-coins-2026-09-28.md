# Typed mempool output coins

The immutable transaction body now exposes its output count and copies a selected output into the existing consensus coin representation. Historical output values, scripts, supplied entry height, noncoinbase flag, confidential flag and commitment are preserved. Orchard outputs use the actual canonical envelope amounts and scripts and remain nonconfidential and noncoinbase. Empty owners and out-of-range indices refuse; they do not produce default coins. The supplied height is existing entry metadata, not a chain-provenance certificate.

The existing mempool prevout fallback, overlay rebuild and conflicted-input recovery consume these methods. Overlay spend marking and branch-removal traversal use the common body's exact input outpoints. They retain the existing pool, coin view, rollback and maintenance owners. Historical-only authorization, selection, relay and persistence remain explicitly restricted; Orchard entry construction does not enable Orchard admission.

## Qualification scope

New benign cases cover immutable historical output metadata including an isolated confidential tuple; actual signed parent/child admission, replacement preflight, refusal, replacement, output recovery and branch removal through the real overlay; empty and out-of-range refusal; and actual canonical Orchard envelope output metadata. The confidential tuple is structural only and is not submitted. The Orchard case does not insert an Orchard transaction into the pool or claim proof verification. Existing fixtures and assertions remain unchanged. Fresh enabled/disabled full daemon builds plus 37 declared targets passed. Each configuration passed 41 component and six daemon CTests. All 72 linked project C++ files were freshly built with ASan/UBSan; four enabled cases passed with 1,301 stable source/header hashes and no project C++ archive members in the instrumented link map. External libraries, Rust, C/PQClean, the daemon and the disabled binary are outside that instrumentation; macOS leak detection was off. All 1,213 prior fixture files and 170 prior Orchard CTest commands remain unchanged. Linux qualification is pending.

This does not implement Orchard admission, nullifier/anchor/balance/resource owners, selected-parent authorization, selection, relay, persistence/readmission, production notifications or independent historical activation validation. Mainnet remains unset and release qualification remains open.
