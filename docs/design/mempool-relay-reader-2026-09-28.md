# Typed network transaction decoding

Actual DaemonApp OnNewTx routes its full payload through DecodeRelayTransaction and passes the resulting immutable body to typed relay ingress. ON reuses ParsedTransaction::DecodeExact. OFF uses the bounded historical serializer and refuses claimed Orchard encoding. Both modes require the entire message, preserve the actual family and own the decoded body after the caller buffer is released.

AvailableFamilies is explicit parsing permission for compiled readers, independent of consensus activation. The actual typed ingress still returns UNAVAILABLE for Orchard validation; this parser enables no Orchard admission, relay announcement or mining. HistoricalOnly explicitly refuses Orchard even in ON builds. No fake historical v7 object or fallback conversion is produced.
