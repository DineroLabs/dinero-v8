# Typed Orchard network block routing

Locally qualified as part of the combined typed block and wallet service integration batch. The actual OnNewBlock callback classifies bounded header bytes using checked stored parent height, or an existing header-selector child when the canonical parent is not yet stored, before historical decoding. Conflicting height/identity, read errors, unavailable owners and unknown parents refuse. No transaction version or current tip guesses the family. The unset release retains historical routing. This classification is not block validity or canonicality.

Typed messages use the actual header-selected download scheduler or actual BlockRelayManager and its bounded canonical queue. While syncing, unsolicited unknown downloads are refused. Raw stateless typed bodies refuse. The stored result is a partial storage result even when an immediate drain fails; it grants no peer credit or parallel-download completion. The ordered callback requires the current chainstate/ingress/parallel owners and exact accepted connected hash/height before terminal parallel completion. Later pruning/telemetry failure cannot relabel canonical acceptance as rejection. The existing parallel wrapper decodes only the historical family. No historical transaction body is manufactured from typed bytes.

Five ON/one OFF patched-path cases exercise real proof-bearing direct routing, provider refusal/retry/reopen, stored-but-unaccepted bytes with retained parallel request followed by actual queued acceptance, historical/stateless/malformed/unknown-parent refusal, sync policy and current exact download owner. No original/race/synchronization-removal controls. Fresh full ON/OFF and all-linked sanitizer qualification required.

These component tests do not execute P2P sockets or establish full service shutdown concurrency, a durable cross-store download catalog, out-of-order multi-block restart, typed backfill/CSN/compact blocks, side-branch state, automatic reorg readmission or the production all-consumer provider. Stored typed bodies still have separate flat-file/scheduler prefixes. No fabricated peer attribution for scheduler-owned completion. Mainnet unset/release incomplete.
