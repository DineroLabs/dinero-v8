# Canonical Orchard block relay completion

Locally qualified as part of the combined typed block and wallet service integration batch. The actual BlockRelayManager acquires configured weak chainstate and ingress services, requires the current context to match both, and classifies the header using its stored parent height and Orchard profile under the selected lock. It releases that lock before passing the exact bytes to the real P2P-origin validation queue. Only a matching connected hash/height permits request completion, seen-state publication and peer delivery credit. A cached seen hash never bypasses current validation; missing providers/owners, stopped queues, historical-family bodies and malformed frames cannot acknowledge a download or grant credit. Operational refusal grants no peer penalty.

Completion bookkeeping follows canonical durability and is retryable. A bookkeeping exception does not relabel an already committed block as rejected. Seen-state/telemetry deduplication is process-local; it is not a durable delivery receipt, lasting canonicality or all-consumer acknowledgment. This path does not manufacture historical bodies, use historical orphan validation, announce compact blocks or silently choose an alternative service. The concrete adapter lives in its own source file so historical-only relay targets retain their dependency boundary.

Four ON/one OFF patched-path cases cover unavailable/expired owners, real proof-bearing queue/provider refusal and retry, actual relay-download completion, exact stored-body reopen/idempotent retry, cached seen-state with stopped/missing owner, and historical/malformed refusal without fallback or credit. Fresh full ON/OFF and all-linked project sanitizer qualification required; no original/race/synchronization-removal controls.

Daemon configuration installs the actual services. Routing OnNewBlock through this typed entry point, header/download/parallel notification coordination, side-branch state validation, typed CSN/backfill/compact blocks, automatic reorg readmission and the production notification provider remain separate work. Mainnet unset/release incomplete.
