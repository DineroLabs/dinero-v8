# Owned Orchard mining templates

The actual BlockAssembler typed entrypoint holds its selected chain owner before acquiring pool access, preserves immutable mixed-family selection, computes exact selected fees and subsidy, and creates a real payout coinbase. Its service-owned constructor rechecks the selected parent, header/time/difficulty, journal, coins, Orchard state and retirement record. It builds DINW, DNRF (including the zero hash of an empty filter), DNRS, the private forest transition and actual external-input batch proof with every ordered spent-input metadata row.

Every draft has its actual encoded body and header hash. Final wire bytes pass complete coinbase, reward, size/weight, script/authorization/resource, state/filter/witness and forest/proof checks before publication. The separate mining header gate omits work only for an unmined template; incoming header validation keeps its proof-of-work requirement. The caller still needs canonical block admission after mining. This is not a selected-state or readiness certificate after the held owner ends.

If full framing exceeds size/weight, the assembler removes only an ordered selection suffix and rebuilds fees and coinbase. Other failures refuse. It neither evicts nor quarantines pool entries. Repeated prefix/proof work is not load/latency qualified. Typed templates are not represented as historical Blocks. The existing daemon assembler factory now supplies the real service-owned guard; historical guard callers retain their contract.
