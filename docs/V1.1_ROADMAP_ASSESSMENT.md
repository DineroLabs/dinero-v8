# Dinero Coin v1.1+ Roadmap: Optional Future Enhancements

**Date**: 2025-11-06
**Status**: Post-v1.0 Production Enhancements
**Timeline**: Weeks 12-52 (3-12 months)

---

## Executive Summary

This document provides a comprehensive assessment of **8 optional future enhancements** planned for Dinero Coin post-v1.0. These features are **not blockers for mainnet launch** but represent major differentiators that will strengthen Dinero's competitive position.

**Current Readiness Overview**:
- **3/8 features** have significant foundation (30%+ ready)
- **2/8 features** have moderate foundation (10-20% ready)
- **3/8 features** require ground-up implementation (0-10% ready)

All features are architected with proper abstractions and can be implemented incrementally without breaking existing functionality.

```cpp
uint64_t PriceOracle::getAggregatedPrice(const std::string& asset,
                                         const std::string& currency) {
    // Get all recent prices (last 5 minutes)
    std::vector<uint64_t> prices;
    for (const auto& update : price_history_) {
        if (update.asset == asset &&
            update.currency == currency &&
            now() - update.timestamp < 300) {
            prices.push_back(update.price_cents);
        }
    }

    // Return median (robust against outliers)
    std::sort(prices.begin(), prices.end());
    return prices[prices.size() / 2];
}
```

```cpp
struct PeerReputation {
    // Negative metrics (already implemented)
    int32_t misbehavior_score;
    uint32_t misbehavior_count;
    bool is_banned;

    // Positive metrics (NEW)
    uint64_t blocks_relayed;
    uint64_t transactions_relayed;
    uint64_t successful_connections;
    double average_latency_ms;
    double uptime_percentage;
    uint32_t peer_referrals;  // How many good peers did they introduce?

    // Composite score
    int32_t reputation_score;  // -100 (worst) to +100 (best)
};

int32_t calculateReputationScore(const PeerReputation& rep) {
    int32_t score = 0;

    // Positive contributions
    score += std::min(rep.blocks_relayed / 100, 20);  // Max +20
    score += std::min(rep.transactions_relayed / 1000, 20);  // Max +20
    score += rep.uptime_percentage > 0.99 ? 10 : 0;  // +10 for 99%+ uptime
    score += rep.average_latency_ms < 100 ? 10 : 0;  // +10 for fast responses

    // Negative deductions
    score -= rep.misbehavior_score;

    return std::clamp(score, -100, 100);
}
```
