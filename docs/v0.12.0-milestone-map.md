### Milestone 12.3 — Coin Selection Engine ✅ COMPLETE

**Status**: Fully implemented (commit 662fb7e3)

**Completed**:
- ✅ Greedy algorithm (`coin_selection.cpp`)
- ✅ Branch-and-Bound (BnB) algorithm
- ✅ Privacy-aware selection

**Implemented Features**:

#### 12.3.1 — Branch-and-Bound Algorithm

**Purpose**: Exact match (no change output) for privacy + lower fees

**Implementation**:
```cpp
CoinSelectionResult SelectCoinsBnB(
    const std::vector<WalletUTXO>& utxos,
    uint64_t target_amount,
    uint64_t fee_rate,
    size_t max_depth = 1000  // Prevent exponential blowup
);
```

**Algorithm**:
- Recursive backtracking
- Find exact match: `sum(selected) == target + fee`
- Fallback to greedy if no exact match

**Reference**: Bitcoin Core's `SelectCoinsBnB()`

#### 12.3.2 — Privacy-Aware Selection

**Purpose**: Avoid common-input-ownership heuristic

**Heuristics**:
1. Prefer same-address UTXOs (if user chose address reuse)
2. Avoid mixing addresses when possible
3. Mix UTXO ages (avoid timing analysis)

**Files to Modify**:
- `include/wallet/coin_selection.h`
- `src/wallet/coin_selection.cpp`

**Exit Criteria** (ALL MET):
- ✅ BnB finds exact matches when possible
- ✅ Greedy fallback works
- ✅ Deterministic selection (under fixed seed)
- ✅ Privacy heuristics applied (group by address, mix ages)

**Implementation**: 1 commit (662fb7e3)

**Algorithm Flow**:
1. Apply privacy heuristics to UTXO set
2. Try Branch-and-Bound for exact match
3. Fall back to greedy if BnB fails/timeout
4. Handle dust threshold (546 una)

**Performance Guarantees**:
- BnB limited to 100,000 iterations (prevents timeout)
- Greedy fallback ensures selection always succeeds
- Privacy-aware ordering applied before coin selection
